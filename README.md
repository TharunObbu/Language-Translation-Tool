# 🌍 Language Translation Tool

<p align="center">

A modern multilingual translation application built with **Python** and **Streamlit**, allowing users to translate text into multiple languages with integrated **Text-to-Speech** functionality.

</p>

---

## 📖 Overview

The **Language Translation Tool** is a user-friendly web application that enables users to translate text between multiple languages using **Deep Translator**. It also provides **Text-to-Speech (gTTS)** support, allowing translated text to be played as audio for improved accessibility and language learning.

---

## ✨ Features

- 🌍 Translate text into multiple languages
- 🔊 Text-to-Speech support
- ⚡ Fast translation
- 🖥️ Clean and responsive Streamlit interface
- 🌐 Supports a wide range of languages
- 💡 Beginner-friendly interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/TharunObbu/Language-Translation-Tool.git
```

### Navigate to the project

```bash
cd Language-Translation-Tool
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```

---

## 💻 Usage

1. Enter the text.
2. Select the source language.
3. Select the target language.
4. Click **Translate**.
5. Listen to the translated text using Text-to-Speech.
