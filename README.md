# Translation Tool

## Overview
This is a simple GUI-based Translation Tool built with Python and Tkinter.  
It uses the `googletrans` library to translate text between different languages.

## Features
- Translate text into multiple languages 🌍
- Simple and user-friendly Tkinter GUI 🎨
- Lightweight and fast ⚡
